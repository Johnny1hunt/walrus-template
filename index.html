Simplified model: 16 nodes, rebuild with any 6. The real network spreads every file across 1,000 shards.

From file to forever, in four steps.

  1. Encode

    Your file becomes a blob. Erasure coding turns it into many small slivers, so you never need every piece to get the whole thing back.

  2. Distribute

    Slivers are sent to storage nodes, which each look after a share of the network's 1,000 shards.

  3. Certify

    Once enough nodes confirm, a proof of availability is recorded on Sui. Anyone can check that your data is there.

  4. Read

    Ask for the blob by its ID. Walrus gathers enough slivers from healthy nodes and rebuilds the original file.

WAL powers the network

Use WAL to pay for storage and to stake on storage nodes that keep your data available.

  • PayBuy storage for a fixed number of epochs.
  • StakeBack reliable nodes and help secure the network.

Coordinated on Sui.

Walrus stores the data. Sui keeps the records. Every blob has an on-chain presence you can own, extend, or build on, with Sui's speed behind it.
